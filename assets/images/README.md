# Images

- `blog/<post-slug>/image-01.ext`: illustrations for a blog post.
- `tutorials/<course>/<day-or-lesson>/image-01.ext`: illustrations for a tutorial lesson.
- `projects/<project-slug>/image-01.ext`: illustrations for a project.
- `favicon.png`: site-wide icon (not an article image).

Keep original image bytes, use descriptive stable slugs, and update every Markdown/HTML reference when moving an image.
