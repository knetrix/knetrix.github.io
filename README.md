# Knetrix GitHub Pages site

Repository target: `knetrix/knetrix.github.io` (user site; URL `https://knetrix.github.io/`).

- Homepage and Just Me remain HTML.
- Project pages are Markdown in `projects/`, rendered with Jekyll.
- Project images are stored in `assets/images/`; add PDFs in `assets/documents/`.
- Do not put passwords, tokens, encryption keys, or real secrets in public site files. Existing project credential values remain `[REDACTED]`.

GitHub Pages is configured to deploy from `main` at the repository root.
